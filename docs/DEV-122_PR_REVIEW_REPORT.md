# DEV-122 — PR 독립 리뷰와 수정

2026-11-03. [PR #416](https://github.com/Myongji-Graduate/MyongjiGraduate-BE/pull/416)의
최초 head `faf28879`를 기준으로 핵심 CLI, 실행 감독기, 평가/리뷰 근거 처리를 독립 context 3개에서 검토했다.
CI 성공과 코드 정확성 검토를 구분했으며, 각 리뷰어는 지정한 파일과 결과 JSON 하나의 소유권을 받았다.
소스 수정은 메인 작업자만 수행했다. 지시 기반 읽기 범위를 OS sandbox로 표현하지 않는다.

## 확인한 결함과 수정

| 지적 | 수정 |
| --- | --- |
| P2: 두 preflight가 리더를 reap한 뒤 같은 숫자의 PGID에 신호를 보냄 | 마지막 그룹 신호 뒤에 리더를 회수해 PID 재사용 창을 제거 |
| P2: stdin close의 BrokenPipe가 나머지 종료 정리를 건너뜀 | stdin 오류 뒤에도 그룹·리더·reader·스트림 정리를 시도. 일반 오류는 정리 후 전파 |
| P2: report와 XML의 총계만 대조해 다른 클래스 결과를 허용 | suite 집합·클래스별 집계·파일명·testcase 소속/중복을 대조 |
| P3: 마지막 LF가 없는 source의 diff 줄이 붙음 | 줄을 구분하고 개행 부재 marker를 출력 |

서버 종료의 mock 검사5개와 리뷰 도구의 새 검사4개는 수정 전 코드에서 실패했다.
수정 뒤 전체 평가 보호 검사51개와 리뷰 도구 검사16개가 통과했다.
종료 처리와 근거 처리의 후속 독립 리뷰에서 기존4건이 해소됐고 새 지적은 없었다.
핵심 CLI의 최초 독립 리뷰도 지적0건이었다. 종료 mock 검사5개는 해당 리뷰어가 별도로 실행해 통과했다.
개행 없는 두 파일의 diff는 합성 저장소에서 `git apply --check --reverse`로도 확인했다.
macOS zombie-only EPERM을 정상 종료와 구분하고, live group의 권한 오류는 실패로 전파한다.

## 근거와 한계

최초 리뷰·수정 전 실패 로그·후속 리뷰는 `build/agent-harness/dev122-pr-review/`에 보존한다.
수정 후 원격 CI는 PR checks와 설명에 해당 head/run을 기록한다. 과거 head의 통과를 새 head의 결과로 표시하지 않는다.
고정 파일럿의 원시 증거와 템플릿은 다시 쓰지 않았다. T04 증거242개가 기존 보존 hash와 일치한다.

이번 수정 검사는 합성 Git/파일과 mock 프로세스 제어를 사용한다. 실제 Codex 종료, PID 재사용,
macOS의 실제 zombie 권한 오류를 새로 실행한 검증은 아니다. 새 모델 코딩 실험·VM/OAuth·HTTP/UI는 실행하지 않았다.
T01 초기 원시 자료의 신뢰 pin 출처는 이번 제한된 코드 리뷰로 확정하지 못했으며,
이를 결함으로 단정하거나 Skill 효과가 검증됐다고 표시하지 않는다. 본 비교30회와 사람 교정은 계속 보류한다.
